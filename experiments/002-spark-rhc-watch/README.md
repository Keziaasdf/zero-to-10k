# 002 — Spark / Robinhood Chain watch

**Read-only.** No es una apuesta activa. Es un tracker para no perderse un drop FUTURO
real y para no caer en scams mientras tanto.

## Por qué existe
- El ecosistema Seedify / Spark / Robinhood Chain está caliente y confuso (3 tokens que la gente mezcla, NFTs con reglas que cambiaron 3 veces, "ETA septiembre" sin fecha firme).
- El `$SPK` de Spark Protocol (Base) **ya cerró su airdrop** (claim vencía 2025-12-17) → nada que hacer ahí.
- Lo único con reward "confirmado" (por palabra de @meta_alchemist, no contrato): **5% del nuevo `$SFUND` a testnet users + token creators** de `vibe/vibe` Season 0. El farming vive en `../../../spark-testnet/` (solo lectura).

## Qué hace este experimento
1. `tracker.md` — contratos / docs / cuentas X **oficiales**, señales de un posible drop futuro, y lista de scams a ignorar.
2. Se revisa en las corridas `HUNT` / `REVIEW`. Si aparece **snapshot + contrato + fecha reales**, se sube a `PIPELINE.md` como idea y se evalúa como spike (nunca apuesta sin score ≥ 70).

## Qué NO hace
- No conecta wallet. No firma. No visita claim sites.
- No ejecuta transacciones en mainnet ni testnet (eso, si se decide, se hace a mano desde `../../../spark-testnet/`).
- No trata rumores ("septiembre", "pronto") como fechas.

## Kill
- Nuevo $SFUND lanza y el 5% a testnet users no se materializa o exige capital → cerrar, quedarse con el contenido.
- 2026-11-01 sin señal firme → archivar el watch.
